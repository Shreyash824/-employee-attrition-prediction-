# Employee Attrition Prediction

A beginner-to-intermediate level machine learning project that predicts employee attrition using a Decision Tree Classifier. Built with Streamlit for interactive deployment.

## Live Demo
[Streamlit App](https://your-app-url.streamlit.app)

## Dataset
IBM HR Analytics Employee Attrition (`WA_Fn-UseC_-HR-Employee-Attrition.csv`)

## Features
- Upload CSV & explore data interactively
- EDA with visualizations
- Label Encoding & preprocessing
- Decision Tree training with adjustable hyperparameters
- Full model evaluation (Accuracy, Precision, Recall, F1, ROC-AUC, PR-AUC)
- Confusion Matrix, ROC Curve, Precision-Recall Curve
- Feature Importance & Decision Tree visualization

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Tech Stack
- Python, Streamlit
- Scikit-learn, Pandas, NumPy
- Matplotlib, Seaborn
